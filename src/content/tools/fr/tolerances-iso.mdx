## Comment lire le tableau

- **es / ei** : écarts supérieur et inférieur de l'arbre (en µm, algébriques).  
  *Ø max arbre = Ø nominal + es/1000 ; Ø min arbre = Ø nominal + ei/1000.*
- **EI / ES** : écarts inférieur et supérieur de l'alésage (en µm, algébriques).  
  *Ø min alésage = Ø nominal + EI/1000 ; Ø max alésage = Ø nominal + ES/1000.*
- **IT** : valeur de tolérance (IT = es − ei = ES − EI), en µm.
- **Jeu max** = ES alésage − ei arbre ; **Jeu min** = EI alésage − es arbre.  
  Une valeur négative de jeu min indique un **serrage garanti**.

## Rappels ISO 286-1

- La position de la tolérance est définie par la **déviation fondamentale** (lettre) :
  minuscule pour les arbres (`h`, `f`, `p`…), majuscule pour les alésages (`H`, `F`, `P`…).
- **h / H** sont les positions de référence (écart nul côté matière) : arbre `h` et alésage `H`
  sont les bases des systèmes d'ajustement à arbre normal et à alésage normal.
- La **qualité IT** définit l'amplitude de la zone de tolérance : IT5 (très précis) → IT12 (grossier).
- Les valeurs calculées sont conformes aux tables de la norme ISO 286-1:2010 pour les diamètres
  de 1 à 500 mm.

## Ajustements courants — guide de choix rapide

| Ajustement | Usage typique |
|---|---|
| H7/f7 | Glissant avec jeu notable — arbre tournant dans palier bronze |
| H7/g6 | Glissant précis — tige de vérin, queue de foret |
| H7/h6 | Centrage sans jeu garanti — montage démontable |
| H7/k6 | Sans jeu / serrage léger — montage précis, centrage répétable |
| H7/n6 | Serrage léger — montage par presse légère ou chauffage |
| H7/p6 | Serrage normal — montage permanent par presse |
| H7/s6 | Serrage fort — montage indémontable, arbre de transmission |
| H8/f7 | Tournant libre — broche, roulement à billes ordinaire |
| H11/c11 | Libre — pièces en environnement poussiéreux |
